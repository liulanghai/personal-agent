# 周报生成

1. 确定笔记范围和日期；缺少日期时注明，不能假定所有笔记属于本周。
2. 读取本次上传的笔记；如需其他文件，先用 list_files 或 search_files 查找。
3. 以明确记载为依据，按以下结构整理：
   - 日期范围
   - 已完成：只列明确定义为完成的工作
   - 进行中
   - 风险与阻塞
   - 下周计划：区分原文计划和建议
   - 待确认信息
   - 来源
4. 用 write_file 在 reports/ 下新建带唯一标识的 Markdown 周报。
5. 检查是否遗漏重要风险，是否将未完成任务误报为已完成。

不得凭空生成进度、指标、日期或负责人；没有相关信息的栏目可标注「材料未提供」。
