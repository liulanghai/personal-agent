# 实施路线图

## P0 · 首版（当前）

- [x] 本地 Git 仓库、依赖锁、示例与文档
- [x] API 优先的 Web 聊天与历史会话
- [x] Web 模型配置（密钥不回传、不提交）
- [x] 文件上传、四个文件工具、Skill 加载
- [x] SSE 持久事件、断线恢复、取消、生成产物
- [x] OpenAPI 与 TypeScript 客户端
- [ ] 真实服务的持续兼容性验证

## P1 · 可靠性与产品交互

- 更完整的事件联合类型与 API 契约兼容性检查
- 结构化错误全统一、游标分页、请求用量与费用记录
- 文件和 Skill 的版本摘要、上下文摘要
- 独立详情面板、键盘操作、可访问性打磨
- 持久 Worker、租约、重试策略、任务安全检查点
- 确认资源与状态机；接入外部写操作前完成

## P2 · 个人知识与持续委托

- Main 与 Executor 共用 Runtime，前台委派后台
- 显式偏好、项目背景、历史决定，来源与修正
- Delegation 长期委托、持久调度、时区和有效期
- 通知 outbox 与幂等发送、订阅游标、变化去重
- 定时任务稳定后增加 Heartbeat，默认无变化保持安静

## P3 · 桌面与高级工具

- 自建桌面客户端复用 SDK/React，优先评估 Tauri 或 Electron
- 本地 Keychain 密钥存储、本地 Connector、系统通知
- MCP 工具映射；PTC 受限编排；沙箱执行代码和浏览器
- 多执行环境、离线等待和能力协商
- 验证后发布 Skill 更新

## 验收主线

上传笔记 → 使用周报 Skill → 读取来源 → 写入产物 → 预览下载 → 重开页面查看记录。

后续扩展为：每周五按上海时区生成周报，后台运行，完成后通知；取消委托后不再触发。
